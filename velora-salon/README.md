# ولورا — سایت سالن زیبایی

سایت تک‌صفحه‌ای استاتیک؛ بدون مرحله‌ی build. فقط HTML، CSS و JavaScript. تصویری استفاده نشده؛ گرافیک با SVG و CSS ساخته شده است.

## ساختار

| فایل | کار |
| --- | --- |
| `index.html` | محتوا، سئو، JSON-LD و ساختار صفحه |
| `styles.css` | پالت رنگی، واکنش‌گرایی و انیمیشن‌ها |
| `main.js` | اسلایدر خطوط خدماتی، فرم رزرو، نشانگر سفارشی |
| `velora-standalone.html` | نسخهٔ یک‌فایلی (CSS و JS داخل خود فایل) برای باز کردن مستقیم در مرورگر |

## پیش‌نمایش محلی

```bash
cd velora-salon
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## قبل از انتشار: موارد باز

1. **آدرس دامنه:** در `index.html` سه جای `https://YOUR-DOMAIN.example` را با آدرس واقعی جایگزین کنید (`canonical`، `og:url`، `og:image` و `image` در JSON-LD).
2. **شماره واتساپ:** در `main.js` ثابت `WHATSAPP_NUMBER` (فعلاً ۰۹۱۹۳۲۲۰۰۳۸) باید روی واتساپ فعال باشد.
3. **ثبت درخواست‌ها (اختیاری):** در `main.js` مقدار `BOOKING_ENDPOINT` را با یک آدرس HTTPS (مثلاً Google Apps Script) پر کنید. اگر خالی باشد، فرم فقط پیام واتساپ می‌سازد.
4. **ساعت کاری:** فعلاً «از ساعت ۸ صبح، تمام روزهای هفته» نوشته شده. ساعت پایان را اضافه کنید.
5. **عکس واقعی (اختیاری):** اگر خواستید عکس خدمات اضافه شود، فایل‌های نهایی را در `assets/` بگذارید و در `index.html` جایگزین بخش گرافیکی کنید.

## انتشار

این سایت هیچ وابستگی به سرور ندارد. هر سرویس میزبانی ثابت این پوشه را منتشر می‌کند:

- **GitHub Pages:** تنظیمات مخزن ← Pages ← منبع را روی شاخه‌ی مورد نظر و پوشه‌ی `/velora-salon` بگذارید (یا محتوای آن را در ریشه‌ی شاخه‌ی `gh-pages` قرار دهید).
- **Netlify یا Cloudflare Pages:** پوشه‌ی `velora-salon` را به‌عنوان پوشه‌ی انتشار انتخاب کنید؛ فرمان build لازم نیست.
